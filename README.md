# LimniFS spec

LimniFS format specification, FlatBuffers schema, registries, and conformance suite.

This repo is the single source of truth for the wire format. The Rust workspace
at [limnifs/limnifs](https://github.com/limnifs/limnifs) pins a spec tag and
regenerates bindings in CI.

Part of the [LimniFS](https://github.com/limnifs) project.
